# LyricCanvas（词绘）

## 项目介绍

LyricCanvas（词绘）是一款开源 Windows 桌面歌词工具。它在桌面显示歌词，并根据 Windows 提供的播放器信息（SMTC)同步播放状态和进度（绝大多数音乐软件不给进度信息）
## 使用说明

1. 从 [GitHub Releases](https://github.com/fiwatere/LyricCanvas/releases) 下载 Windows x64 便携包。
2. 完整解压 ZIP 文件，然后运行文件夹中的 `lyc.exe`。程序需要同目录文件，请保留整个文件夹。
3. 首次运行后，可通过系统托盘图标打开设置。将本地 `.lrc` 歌词放入设置指定的目录，或启用联网获取歌词。
4. 播放歌曲时歌词会自动在桌面显示，也支持显示自定义文本。当前测试网易云音乐需安装第三方插件 **InfLink-rs**获取完整SMTC；酷狗音乐则需打开”播放“设置里的支持系统播放控件。其他音乐软件暂未测试。
5. 播放进度同步取决于播放器提供的 Windows SMTC 信息。部分播放器可能需要额外的第三方插件；相关风险见下方声明。
