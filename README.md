# LyricCanvas（词绘）

Windows 桌面歌词叠加工具，简称 LC，可执行文件为 `lyc.exe`。
当前正式版是 **1.0.0**。
词绘负责歌词获取、进度同步和自由排版，音乐仍由用户自己的播放器播放。

## 运行与退出

发布包面向 Windows x64，建议 Windows 10 2004 或更高、Windows 11。
完整解压便携 ZIP 后，双击包内的 `lyc.exe`；程序依赖同目录中的文件，不能只复制 EXE。
使用自带运行时的发布包时，无需另装 .NET；源码开发需要 .NET 8 SDK。

首次运行后，用托盘图标打开设置。默认关闭设置窗口后仍在后台显示歌词。
要结束程序，选择托盘菜单的“退出”；可在设置里关闭“后台运行”。
程序支持自定义文本模式，适合在桌面显示固定文字。

## 歌词与同步

词绘读取 Windows 系统媒体会话（SMTC）的曲名、歌手、播放状态和时间轴。
**完整播放位置必须由播放器或独立桥接插件提供**，词绘无法生成播放器没有公开的位置。
播放器名称被识别不代表时间轴完整：请在“歌词来源”页查看来源、报告位置和更新时间。

当来源提供有效时间轴时，播放、暂停、恢复、拖动与循环可按其位置刷新歌词。
若来源只提供曲名和播放状态，词绘会进行本地进度估算；拖动后的精确同步无法保证。
默认识别音乐播放器，浏览器和视频软件的会话不会自动接管歌词。
未知音乐播放器可将其 App ID 加入“允许的其他播放器”列表。

歌词读取顺序是：**用户自己的 LRC 文件 → 缓存 → 联网搜索**。
当前联网来源包括酷狗歌词接口和 LRCLIB，第三方服务的结果与可用性可能变化。
联网获取歌词与 SMTC 获取进度是独立过程；歌词找到不代表播放位置可用。

要离线使用，把 `.lrc` 放到设置指定的歌词目录、程序目录下的 `lyrics`，
或启动时的当前工作目录下的 `lyrics`；词绘按这个顺序依次查找并跳过重复路径。
文件名可使用 `曲名.lrc` 或 `曲名 - 歌手.lrc`；有效 SMTC 进度同样可同步本地歌词。
联网开关关闭后仍可读取用户文件和已保存缓存。
设置里的“清空缓存”只删除 `lyrics/cache` 顶层中可确认由词绘管理的缓存歌词；未知文件、子目录和重解析点会保留。无身份记录的旧版缓存不会命中，仍保留到用户清理。
逐首歌词偏移可用于调整歌词版本造成的固定时间差，不替代有效播放进度。

## 布局与外观

默认两个透明歌词框轮流显示句子，最多可配置 10 个框。
播放时框无背景、无边框，可置顶与鼠标穿透；位置统一在全屏布局编辑器调整。
布局方案分别保存框数量、位置、尺寸和旋转，启动时恢复上次使用的方案。

打开编辑器：托盘“调整布局”，设置“窗口行为”，或默认快捷键 `Ctrl+Alt+E`。
在编辑器中拖动框、拖右下角缩放、拖顶部圆点旋转，文字与框一起旋转。
可新增、切换、重命名和删除方案，并导入图片或截取屏幕作为静态参考背景。
参考背景只保存在内存，不修改导入的原文件；按 `Esc` 或“完成”结束布局编辑。

“歌词显示”包含基础、颜色、动态效果、播放效果和显示内容设置。
基础设置包括字体、字号、透明度和字间距，支持导入 `.ttf` / `.otf` 字体。
导入字体复制到词绘的用户数据目录，不安装为系统字体。
全局文字颜色支持按顺序排列的横向渐变色标；单个色标表示纯色。
动态效果包括上下晃动、左右晃动、粒子散开，并提供周期或粒子参数。

播放效果始终且只能启用一项：**淡入淡出**或**从左至右高亮**。
淡入淡出支持独立时长和停留上限；启用“同一歌词框保留到下一句”时，
停留上限与该框下一句的切换条件同时有效，先到的条件触发淡出。
从左至右可分别设置已播放与未播放颜色，启用的效果颜色优先于全局文字颜色。
未设置覆盖色时沿用全局颜色，未播放部分使用淡化后的全局颜色。

普通 LRC 只有每句起始时间，因此从左至右按句子区间估算推进。
增强 LRC 带 `<mm:ss.xx>` 词或音节时间戳时，按这些时间戳推进；
SMTC 提供歌曲位置，不提供每个字的演唱时间。歌词文件的细粒度时间戳决定准确度。

## 修改与保存

歌词显示设置使用草稿：修改时实时预览，点击“确认并保存”才持久化。
点击“取消修改”恢复编辑前配置，关闭未保存的设置时可选择保存、放弃或继续编辑。
全局样式由所有方案共享，各布局方案分别保存框的位置、尺寸和旋转。
配置仍支持单框字号、文字颜色和透明度覆盖值。

当前配置格式版本为 **7**，旧配置会按兼容规则迁移。
默认文件是 `%APPDATA%\LyricCanvas\config.json`，例如：
`C:\Users\Alice\AppData\Roaming\LyricCanvas\config.json`。
保存遇到权限问题时依次尝试 `%LOCALAPPDATA%\LyricCanvas\config.json`
和程序目录的 `LyricCanvas.user.json`，启动时读取可用配置中最近保存的一份。
导入字体位于 `%APPDATA%\LyricCanvas\Fonts`；旧 `LyricDesktop` 配置保留用于迁移。

## 实验功能

“实时歌词校准”默认关闭：开启后捕获系统输出音频，在本机识别并与 LRC 匹配。
此功能需要 Windows 11，首次启用会下载语音模型，识别音频不上传。
系统中其他应用的声音也可能进入识别缓冲，歌声、伴奏和重复句会影响结果。
实验功能的延迟和资源开销较高，不能代替播放器或桥接插件提供的完整 SMTC 时间轴。

## 开发结构

```text
LyricCanvas.sln
Directory.Build.props               公共编译设置
src/
  LyricCanvas.Core/                 配置、LRC、匹配、时间轴等纯逻辑
  LyricCanvas.Media/                SMTC、联网歌词来源、实验音频校准
  LyricCanvas.App/                  WPF、托盘、布局与窗口管理
    Settings/                      设置界面及按职责拆分的 partial 文件
    Rendering/                     共用文字画刷与渲染辅助
tests/
  LyricCanvas.Core.Tests/           跨平台纯逻辑回归
  LyricCanvas.Media.Tests/          假 HTTP 请求与取消/释放回归
  LyricCanvas.App.Tests/            WPF 画刷与布局测量离线检查
tools/                             构建、离线验证与发布脚本
docs/                              用户便携包说明
artifacts/                         忽略的验证和发布产物
lyrics/                            用户自己的歌词目录
```

## 构建与检查

在仓库根目录执行：

```powershell
dotnet build LyricCanvas.sln
dotnet run --project src/LyricCanvas.App
```

执行离线回归检查：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/verify-all.ps1
```

该脚本只构建和运行离线测试，输出到 `artifacts/check`，不操作界面或用户进程。
首次恢复 NuGet 依赖可能需要网络；测试本身不访问歌词服务或真实播放器。
## 生成正式版便携包

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/publish-portable.ps1
```

该脚本只发布 App 项目，Windows x64 自带运行时，产物放在 `artifacts/packages`。
分享生成的 ZIP；接收方完整解压并运行 `lyc.exe`，保留整个发布目录。
发布包不会携带开发者的用户设置或导入字体，首次运行从默认设置开始。

## 删除与反馈

免安装版没有独立卸载程序：先退出词绘，再删除解压出的整个程序目录。
要清除个人设置和字体，再删除 `%APPDATA%\LyricCanvas`；
若存在回退数据，也可删除 `%LOCALAPPDATA%\LyricCanvas`。
例如 Alice 的目录是 `C:\Users\Alice\AppData\Roaming\LyricCanvas`。
分享包中的具体使用和删除说明应随包保留。

反馈请注明版本、Windows 与播放器版本、是否使用 SMTC 桥接插件、重现步骤。
同步问题优先附“播放器识别与同步诊断”中的报告位置、估算位置和状态变化。
便携包使用与卸载方法见 [文档索引](docs/README.md)。
